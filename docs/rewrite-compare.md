# 去广告重写比对报告

检查日期：2026-11-22。方法是**静态比对**，没有在 iPhone 上实际运行。

1. 下载每份重写，解析出重写规则、MITM 主机名和引用的脚本
2. 引用的脚本逐个下载，用 `node --check` 检查 JS 语法
3. 正则逐条编译。fmz200 合集里有 21 条用了 `(?>...)` 原子组，JS 不支持，但 iOS 的正则引擎支持，不算错误
4. 用 randexp 按每条单项规则的正则生成样例 URL，再拿去匹配 fmz200 合集的全部规则。两边都能匹配算“重叠”；重叠时动作或脚本不同，算“冲突”

## 补充说明

- fmz200 合集里还有 2760 条分流规则（`host-suffix, …, reject`），与它的 `filter.list` 完全相同，本仓库的 `rules/AdBlock.list` 已包含这些规则。
- 微博重写里有一条“解锁微博会员图标”（`weibo_vip.js`），只改图标外观。不需要的话可以在本地复写里覆盖掉。
- 知乎：如果合集对知乎效果不好，可以**关闭合集里的知乎部分**再打开 blackmatrix7 知乎。不要两个同时开。

## 还需要真机确认

静态比对只能证明“链接可用、语法正确、不互相冲突”。App 更新接口后规则可能失效，这一点只有实际打开 App 才能看到。建议在手机上逐个打开 YouTube、B 站、高德、微博、知乎，看开屏和信息流广告还在不在。
